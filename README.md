# Performance-overview-
Data Analyst Sales Performance overview Report
 
My task is to use the data contained within the Excel file (titled 'SimulationFile.xlsx') to create a Power BI data model using industry best practices. My work involved recreating a screenshotted report from the Excel file and designing an additional 1–2-page demo report to showcase my skills and capabilities in terms of both data analysis and report design. The report is created using only the data provided in the Excel file, no external datasets or tables to the data model (other than the Sales data) was added.

Data Model Quality: The effectiveness and adherence to best practices in creating the Power BI data model. The data model follows best practices such as a star schema, avoiding circular dependencies, and optimizing performance.

Transformations and Calculations: The accuracy and efficiency of the transformations and calculations applied to the data. Maintained the integrity of the provided data. Alterations to the data are made when necessary for transformations or cleaning.

Report Design: My ability to recreate the screenshotted report with attention to detail, visual aesthetics, and adherence to design elements (such as colors, fonts, and layout). 
Demo Report: The creativity and presentation of my demo report.
